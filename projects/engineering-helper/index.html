01 / Product problem

Reduce friction in everyday mechanical design work.

Common engineering tasks are spread across handbooks, bookmarked websites, spreadsheets, reference charts, calculators, and handwritten notes. The goal is a coherent workspace that shortens lookup time without hiding assumptions, units, or equations.

  • Fast accessReach common tools in a few clicks with a clear dashboard and search hierarchy.
  • Unit awarenessKeep inputs, outputs, material values, and calculated properties consistent across unit systems.
  • Transparent calculationsShow equations, variable definitions, assumptions, and valid ranges where useful.
  • Practical referencesPrioritize threads, drills, fits, materials, fasteners, geometry, beams, and seals.
  • Progressive complexityKeep simple tasks quick while allowing advanced inputs and explanation when needed.
  • Engineering notesSupport movable text, sketches, arrows, dimensions, and grid-paper thinking.

02 / Module architecture

One workspace, organized by design task.

Core

Calculators

Regular, scientific, graphing, geometry, mass, unit conversion, and persistent calculation history.

Hardware

Fasteners & Threads

Metric, UNC, and UNF data; drills, torque guidance, joint checks, and explanatory references.

Design

Tolerances & Fits

Tolerance stack-up, fits and clearances, drawing references, and GD&T guidance.

Analysis

Structures

Section properties, beam bending, material reference, and geometry-based calculations.

Sealing

O-Rings & Glands

Guidance for seal selection, gland geometry, squeeze, and design-check workflows.

Workspace

Engineering Notebook

Grid paper with movable/resizable text, drawing, arrows, dimensions, and flexible note layout.

References

Materials & Tables

Metals and plastics, common properties, drill references, standards, and compact lookup tables.

Process

Design Checklist

Prompts for requirements, loads, interfaces, tolerance, DFM, verification, and release readiness.

Roadmap

Machine Elements

Bearings, springs, gears, belts/chains, welds, fatigue, pressure vessels, and vibration tools.

04 / Iteration model

Use real design work to expose failure modes.

The tool is developed through use, not only feature checklists. Problems such as incorrect unit propagation, incomplete expression parsing, calculator memory behavior, and awkward notebook interaction become explicit revision inputs.

01Use the tool
02Observe friction
03Revise behavior
04Regression test
Product principle

A compact tool is only useful if its units, state, equations, and interaction behavior are trustworthy.
